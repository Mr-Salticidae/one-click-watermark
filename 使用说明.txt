一键加水印工具使用说明

使用方法：
1. 把“一键加水印.exe”和需要处理的 PNG、JPG、JPEG 或 PDF 文件放在同一个文件夹里。
2. 双击“一键加水印.exe”。
3. 第一次运行会自动生成“水印设置.json”。
4. 如果需要修改水印，按提示输入 y；如果不需要修改，直接回车。
5. 等待窗口提示“处理完成”。
6. 查看自动生成的两个文件夹：
   - 尝鲜版
   - 完整版

可自定义内容：
- trial_text：尝鲜版水印文字。
- full_text：完整版水印文字。
- font_path：字体文件路径。留空时会自动查找系统常见字体。
- font_size：水印字号，范围 12-300。
- row_count：每张图片水印行数，范围 1-20。
- rotate_degrees：水印旋转角度，范围 -90 到 90。
- opacity_percent：水印透明度百分比，范围 1-100。

字体说明：
- Windows 会优先查找宋体、微软雅黑、黑体等系统字体。
- macOS 会优先查找苹方、华文黑体、Arial Unicode 等系统字体。
- 也可以把字体文件放到工具同一文件夹，命名为“字体.ttf”或“字体.ttc”。
- 如果字体文件路径包含空格，可以直接写完整路径，不需要加引号。

macOS 使用方法：
1. 安装 Python 3。
2. 在终端进入本工具所在文件夹。
3. 安装依赖：python3 -m pip install pillow pymupdf
4. 运行：python3 一键加水印.py
5. 需要打包时，可安装 pyinstaller 后执行：pyinstaller 一键加水印.spec

注意：
- 原图不会被修改。
- 会自动处理工具同一文件夹内的 PNG、JPG、JPEG 和 PDF 文件。
- 如果重复运行，同名输出图片会被新的结果覆盖。
- 请不要把原图放进“尝鲜版”或“完整版”文件夹里。
